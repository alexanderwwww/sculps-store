# Auto-trader research (2026-10-28) — no clicking, same shape as the screenshot bot

Tested from the container, free, no key:
- RugCheck: GET https://api.rugcheck.xyz/v1/tokens/{mint}/report/summary -> {risks[], score, score_normalised, lpLockedPct} (answered 200).
- DexScreener: GET https://api.dexscreener.com/latest/dex/tokens/{mint} -> pairs, price, liquidity (answered 200).
- Jupiter: GET https://lite-api.jup.ag/swap/v1/quote?inputMint=SOL&outputMint={mint}&amount=16180000&slippageBps=300 -> route incl. Pump.fun, priceImpactPct (answered 200). POST /swap returns a transaction to sign.
Public claims (vendor pages, unverified): Jito bundles for ordering/MEV, tight slippage, exits like TP 2-3x / SL -15%. CoinGecko: share of profitable pump.fun wallets 30% (Jun 2025) to 73% (Apr 2026) but wins are small. No study of bot win rates.

Pipeline: scanner -> rug check -> sizer -> executor -> logger -> equity. Every decision logged with a reason.
Needs: a dedicated hot wallet key held ONLY by Alex's Mac app (never by Claude), funded with a small amount. Backtest + paper first; our own sim won 77/501, so no live money until the new filters beat it.

## Ultra build 5 (2026-10-28): fast, frequent, animated (Alex: "trade fast, instantly, a lot")
- Two lanes. FAST (every 3 s): DexScreener batch quotes (30 pools/0.25 s call) -> live exits (stop/trailing/target/time) and entries built from the cached minute chart plus the minute in progress. SLOW: GeckoTerminal (30 calls/min) for discovery, charts, shadow book, and a chart backstop for exits. A restart bug is fixed: the chart is judged from the real entry, not the window start.
- Limits raised on request: 4 open, 30 buys/h, 200/day (0.05 SOL per trade, 12%, 30% halt, never Kimchi unchanged).
- Protections from the 500 practice trades: skip coins already up >150%, skip when buyers < 52% of 5-min flow, shadow paper edge gate.
- Animated flow on the dashboard driven by real engine events (scan dot -> rug check -> sizer -> executor -> logger).
- Settings tuned on 144 real young pools (data/pools.json via collect.mjs; tune.mjs judges on pools it never saw, against random entries): lookback 5, volume 1.5x, target +90%, stop -15%, trail +22%/-10%, hold 60 min. HONEST READ: unfiltered by liquidity it averaged +14%/trade on unseen pools (63% wins, n=32), but random entries on the same sample average +2% (the sample is biased toward pools that pumped), and with a liquidity filter proxied by today's liquidity the backtest is about +1%/trade, 41% wins (n=17). Edge is NOT proven; the forward shadow book decides. Start small.
