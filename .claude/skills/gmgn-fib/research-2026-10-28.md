Tested from the container, free, no key:
- RugCheck: GET https://api.rugcheck.xyz/v1/tokens/{mint}/report/summary -> {risks[], score, score_normalised, lpLockedPct} (answered 200).
- DexScreener: GET https://api.dexscreener.com/latest/dex/tokens/{mint} -> pairs, price, liquidity (answered 200).
- Jupiter: GET https://lite-api.jup.ag/swap/v1/quote?inputMint=SOL&outputMint={mint}&amount=16180000&slippageBps=300 -> route incl. Pump.fun, priceImpactPct (answered 200). POST /swap returns a transaction to sign.

Pipeline: scanner -> rug check -> sizer -> executor -> logger -> equity. Every decision logged with a reason.
Needs: a dedicated hot wallet key held ONLY by Alex's Mac app (never by Claude), funded with a small amount. Backtest + paper first; our own sim won 77/501, so no live money until the new filters beat it.

- Own wallet (Jupiter) and GMGN API keys remain under Advanced.
- Proven here against headless Chrome + a fake GMGN page shaped like what ultracursor's probe read; NOT yet proven on his real GMGN page. Zip includes playwright-core (the Chrome driver).
