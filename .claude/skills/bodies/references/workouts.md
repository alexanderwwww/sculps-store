# BODIES WORKOUT ECOSYSTEM

## Core idea
The machine is not only a Pilates device.

It is a compact movement platform that can deliver a complete home routine.

## Main categories

### PILATES
Reformer-inspired Pilates flows:
- Footwork.
- Bridging.
- Leg circles.
- Plank/elephant variations.
- Kneeling work.
- Side-lying work.
- Controlled full-body sequences.

### SCULPT
Customer-facing focus:
- Glutes.
- Legs.
- Arms.
- Core.
- Full-body tone.

This category should use language customers naturally understand.

### CORE
- Controlled core sequences.
- Anti-rotation.
- Plank variations.
- Abdominal endurance.
- Pilates-based core work.

### GLUTES
- Hip extension.
- Abduction/adduction where appropriate.
- Bridges.
- Leg work.
- Resistance-based sculpt sequences.

### ARMS
- Cable/band upper-body work.
- Pilates arm sequences.
- Shoulder/posture work.
- Light resistance sculpt.

### LEGS
- Lower-body resistance.
- Pilates footwork.
- Controlled sculpting.

### STRETCH
- Full-body mobility.
- Post-workout stretching.
- Gentle flexibility work.

### RECOVERY
- Low-intensity movement.
- Mobility.
- Stretch.
- Relaxed guided sessions.

### STRENGTH
A more resistance-focused category:
- Upper body.
- Lower body.
- Full body.
- Progressive resistance.

### FULL BODY
Complete guided sessions combining multiple movement types.

## Screen experience
The product UI should make category discovery easy.

Potential left navigation:
- Home
- Pilates
- Strength
- Stretch
- Recovery
- Programs

Main content:
- Hero workout.
- Recommended sessions.
- Categories.
- Recent workouts.
- Programs.
- Progress.

## Important product experience principle
The machine should never feel like it has a screen attached just for marketing.

The screen must clearly make the product better:
- It teaches.
- It guides.
- It times.
- It organizes.
- It motivates.
- It helps users choose what to do.

## Validation
Before manufacturing, test:
1. Whether Pilates instructors believe the movement mechanics are sound.
2. Whether users can understand how to set up each exercise.
3. Whether resistance feels appropriate.
4. Whether the machine feels stable.
5. Whether the screen is positioned correctly.
6. Whether users can carry/store it.
7. Which workout categories drive the most interest.
