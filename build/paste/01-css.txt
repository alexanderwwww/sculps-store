/* ==========================================================================
   FIX 10: smooth mobile navigation (CSS only, additive).
   ==========================================================================
   Evidence for each rule:
   - xero-theme.css sets body{overflow-x:hidden} and, on mobile,
     body{overflow:auto; overscroll-behavior-y:contain}. There is no momentum
     scrolling hint, no smooth anchor scrolling, and nothing pins the scroll
     axis to the root, so an inner scroller's rubber-band can chain to the page.
   - xero-store.js scrollTo() already uses {behavior:'smooth'} for its own
     anchor jumps; scroll-behavior:smooth makes native #anchor / keyboard
     paging match it. Respect reduced-motion (see the block below).
   - The stage (66svh), the marquee/coaster row ([data-anim] with xmarq) and the
     photo rail ([data-m="rail"]) are the wide/overflowing elements; keep their
     overscroll from chaining to the document and give the rail iOS momentum. */

  html{ scroll-behavior: auto; }
}

  [data-m="coaster"], [data-m="stage"]{ overscroll-behavior: contain; }

   ==========================================================================

/* XERO - UGC carousel, captionless.

   The cards were designed with a name chip and a caption over the bottom of each shot, so
   xero-ugc.liquid paints a scrim there: a gradient covering the bottom 52% of the frame,
   reaching 60% black at the base. That exists purely to keep white text legible.

   With the captions removed there is no text to protect, so the scrim is just half of
   every photograph needlessly darkened. It comes off - unless a block still carries a
   caption, in which case it comes back for that card only.

   .ugc-meta is only rendered when a block has a handle or a caption (see the section's
   {% if %}), so :has() reads the real state rather than a duplicated flag. A browser
   without :has() simply never shows the scrim, which is the correct look here anyway. */

.ugc-frame::after{ display: none !important; }
.ugc-card:has(.ugc-meta) .ugc-frame::after{ display: block !important; }
